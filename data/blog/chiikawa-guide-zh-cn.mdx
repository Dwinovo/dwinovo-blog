# 这是什么模组？

**Chiikawa Mod** 是一个把动漫《Chiikawa》里那群治愈系小动物搬进 Minecraft 的非官方模组。

它不是一个"换皮宠物"模组。除了在野外随机刷新的 7 位角色，模组还做了一整套**驯服系统**、**职业系统**、**复活仪式**，以及 0.0.4 全新引入的**自定义音乐演奏系统**。你的存档会从此多出一个角色：那群偶尔吵闹、偶尔贴心、能种地能打架、还会现场弹吉他的小伙伴。

## 📥 如何下载

模组已正式上架 **[CurseForge](https://www.curseforge.com/minecraft/mc-mods/chiikawa)**。推荐直接在启动器里安装，不必手动下载：

1. 打开你的启动器（PCL2、HMCL 都行）。
2. 进入 **「下载」→「模组」** 页面。
3. 搜索关键词：`Chiikawa`
4. **小提示**：如果搜不到，把分类筛选改成 **「生物群系 (Biomes)」** 再试一次。

## 🐾 角色阵容

模组共加入 **7 位** 可驯服的小生物。所有角色基础数值一致（**20 点生命值、0.3 移动速度**），但每位都拥有专属的叫声与互动音效；部分角色还有专属武器或职业。

| 角色                     | 简称         | 特别之处                                                                     |
| :----------------------- | :----------- | :--------------------------------------------------------------------------- |
| **乌萨奇 (Usagi)**       | 兔兔         | 拥有独立攻击与闲置叫声，专属武器 **乌萨奇的讨伐棒**（铁剑属性 + 火焰附加 I） |
| **小八 (Hachiware)**     | 蓝色小耳朵   | **唯一能担任音乐家** 的角色；专属武器 **小八的讨伐棒**（石剑属性 + 击退 I）  |
| **吉伊 (Chiikawa)**      | 主角本人     | 专属武器 **吉伊的讨伐棒**（石剑属性 + 击退 I）                               |
| **狮萨 (Shisa)**         | 黄色小狮子   | 治愈系陪伴                                                                   |
| **飞鼠 (Momonga)**       | 想被夸的飞鼠 | 治愈系陪伴                                                                   |
| **栗子馒头 (Kurimanju)** | 圆滚滚       | 治愈系陪伴                                                                   |
| **獭师父 (Rakko)**       | 强者         | 治愈系陪伴                                                                   |

> 创造模式可以在专属创造物品栏「Chiikawa」中找到全部 7 种 **刷怪蛋**、7 种 **玩偶**、3 把 **讨伐棒**，以及 1 个 **八音盒**——共 18 件物品。

## 🌏 野外邂逅

野生角色会在以下生物群系自然刷新，集中在温暖与温和地带：

- **平原类**：平原 (Plains)、向日葵平原 (Sunflower Plains)
- **热带类**：热带草原 (Savanna)、热带高原 (Savanna Plateau)、沙漠 (Desert)
- **其他**：沼泽 (Swamp)、雪原 (Snowy Plains)

所有角色刷新权重一致，**单只出现**（不会成群），可以理解为偶遇——找到一只就是命中注定。

## 💖 驯服与日常互动

### 1. 驯服方式

手持食物，**右键** 喂给野生角色即可尝试驯服。

- **成功率**：每次喂食 **30%** 概率成功。
- **代价**：无论成功与否食物都会消耗 1 个，所以多备几组。
- **成功瞬间**：会播放该角色专属的驯服音效，并伴随一段开心的小动画。
- **失败瞬间**：角色会做出"困惑挠头"的小动作——再喂下一颗就好。

### 2. 食物清单

绝大多数原版可食用物品都能投喂：

> 🍎 **水果与蔬菜**：苹果、胡萝卜、金胡萝卜、西瓜片、马铃薯、甜浆果、发光浆果、甜菜根
>
> 🍖 **肉类 (熟食)**：牛排、熟鸡肉、熟猪排、熟羊肉、熟兔肉、熟鳕鱼、熟鲑鱼
>
> 🍞 **烘焙与零食**：面包、烤马铃薯、曲奇、南瓜派、金苹果
>
> 🥣 **汤品与饮品**：蘑菇煲、兔肉煲、蜂蜜瓶

### 3. 驯服之后

- **回血**：上面任意一种食物都能用来给已驯服的伙伴回血，**每次 +4 生命**（满血时不消耗食物）。
- **背包**：直接 **右键** 已驯服的伙伴打开它的背包面板，共 **16 格**。
- **装备主手**：背包里第 1 格是 **主手槽位**——把工具放在这里，它就能据此自动切换职业。

> 💡 该模组目前**不支持繁殖**——每一只都是从野外驯服来的独立伙伴。所以请善待你的小队成员。

## 🧠 三种行为模式

对着已驯服的伙伴 **蹲下 + 右键** 可以循环切换三种模式，每次切换屏幕上方会有动作条提示。

### 1. 跟随模式 (Follow) — 默认

像个甩不掉的小尾巴跟在你身后。

- 距离超过 **7 格** 时它会加速跑向你。
- 距离超过 **20 格** 时它会直接传送到你身边（防止你打副本时把它落在洞口外）。

### 2. 坐下模式 (Sit) — 乖巧待机

留在原地不动，但目光会跟随附近的实体——你能感觉到它在看你。

- 不会移动，不会触发传送。
- 适合临时打 boss、做精密红石时把它先安置好。

### 3. 工作模式 (Work) — 自动化打工

切到这个模式的瞬间，它会把当前位置记录为"工位"，然后根据主手物品执行对应职业的工作逻辑。

- 没事做时会在工位附近溜达，**不会跑远**。
- 详细的职业逻辑见下一节。

## 🛠️ 职业系统

伙伴的职业由 **主手物品** 自动决定，更换工具即可换职业。

### 🌾 农夫 (Farmer)

**需求**：主手持有任意 **锄头**。

工作逻辑（仅在工作模式生效）：

1. **自动收割**：探测周围已成熟的 **小麦、马铃薯、胡萝卜、甜菜根、西瓜、南瓜**。
2. **自动补种**：从自己的背包里取出对应种子重新种回去（小麦种子、甜菜种子、南瓜种子、西瓜种子、马铃薯、胡萝卜）。
3. **自动归仓**：发现身边有 **箱子 / 陷阱箱 / 木桶 / 漏斗**，会主动把收获物存进去。

把它丢进村庄农场或者你的圈养系统里，自动化产线就有了。

### ⚔️ 剑士 (Fencer)

**需求**：主手持有任意 **剑**（包括原版六种剑 + 模组三把讨伐棒）。

- 主动攻击附近的敌对生物：僵尸、骷髅、蜘蛛、灾厄村民系列（劫掠者、卫道士等）、烈焰人、恶魂等。
- 攻击节奏比较稳，挥剑间隔约 1 秒。

### 🏹 弓箭手 (Archer)

**需求**：主手持有 **弓** + 背包里有 **箭**。

- 攻击目标与剑士相同，但会保持距离用弓远程射击。
- 支持 **无限附魔**——附了无限的弓只要带一支箭就够。

### 🎸 音乐家 (Musician) <span className="ml-1 align-middle text-[10px] font-bold tracking-wide text-pink-600 dark:text-pink-400">NEW</span>

**需求**：**小八专属**——主手持有已选好歌曲的 **八音盒**。

- 切到工作模式后，小八会自动抱起吉他开始演奏，附近的玩家都能听到。
- 演奏过程中它的吉他模型会出现，嘴部表情骨骼也会激活——是认真在弹的。
- 如果在演奏中被怪物袭击，演奏会自动中断，等冷静下来再继续。

> 详细玩法见下方 [八音盒与自定义音乐](#-八音盒与自定义音乐) 一节。

## 🎵 八音盒与自定义音乐

0.0.4 版本的核心新玩法。你可以把任何想听的歌带进 Minecraft，让小八现场为你和附近的玩家演奏。

### 1. 准备 FFmpeg

模组需要借助 **FFmpeg** 把各种格式的音频转成游戏内可用的格式。

- 大多数主流系统上 FFmpeg 都可以一键安装（Windows 装好后记得把它加入 PATH）。
- 如果模组检测不到 FFmpeg，八音盒 UI 会弹出醒目的提示与"重新加载"按钮——装好后点一下即可，不用重启游戏。
- 服务器管理员也可以通过 `/chiikawa music ffmpeg status` 命令检查 FFmpeg 状态。

### 2. 导入你的歌单

进入服务端（或单人世界）的配置目录 `config/chiikawa/music/`，把任意常见格式的音频丢进去：

> 🎼 **支持格式**：mp3 / wav / flac / m4a / ogg ……基本上 FFmpeg 能读的它都能读。

模组会在后台自动转码。单曲时长默认上限 **10 分钟**，可在 `config/chiikawa/music.json` 中调整。

### 3. 在八音盒里选歌

手持八音盒 **右键** 打开歌曲列表：

- 已成功导入的曲目可以直接点击选中。
- 选中后物品名上会显示当前曲目（例如 `歌曲：xxx.mp3`）。
- 正在导入的曲目会标记为 **「导入中」**，导入失败的会标记为 **「导入失败」**。

### 4. 让小八演奏

1. 右键已驯服的小八打开背包，把 **八音盒** 拖到 **主手槽位**。
2. 蹲下 + 右键切换到 **工作模式**。
3. 小八会自动抱起吉他开演 🎶。

默认 **32 格范围内** 的所有玩家都能听到这段音乐——可以理解为一个会动的 BGM 喇叭。

### 5. 小贴士

- **多人演奏会**：让多只小八各自演奏不同的歌曲，做个森林音乐节。默认并发上限 4 首。
- **战斗优先级**：演奏过程中如果被敌人攻击，演奏会自动暂停，等小八没有敌对目标后会继续。
- **管理员命令**：`/chiikawa music rescan` 可以强制重新扫描音乐目录，新放进去的歌不用重启服务器即可生效。

## 💀 死亡与复活：玩偶 + 蛋糕仪式

> ⚠️ 这是一个隐藏机制——很多玩家根本不知道。读完这节，伙伴再也不会"白死"。

### 1. 死亡时发生了什么

当伙伴生命值归零，它不会像原版宠物那样彻底消失——**它会原地掉落一个对应种类的「玩偶」**。

这个玩偶里完整保留了它的：

- 整个 **16 格背包内容**
- 当前 **行为模式**（跟随 / 坐下 / 工作）
- **职业** 配置
- 你给它起的 **名字**
- 与你之间的 **主人关系**

也就是说：**死亡 = 暂时变成一个可携带的玩偶，未来可以原地复活。**

> 💡 玩偶的物品提示文本里有一行小小的提示：「试着把玩偶放在蛋糕上？」——这就是关键。

### 2. 复活仪式

需要的材料非常简单：

- ✅ 1 个 **对应种类的玩偶**（即死亡时掉落的那个）
- ✅ 1 块 **蛋糕**（任意吃剩状态都行，整块或者已经吃过几口都可以）

操作步骤：

1. 放置一块蛋糕。
2. 手持玩偶，**右键** 蛋糕。
3. 蛋糕会被吃掉一口（已吃到最后一口的会消失），玩偶被消耗。
4. 头顶开始飘出 **绿色开心粒子 + 爱心粒子** 持续约 **3 秒**。
5. 时间到，伙伴从蛋糕处复活——满血、保留所有数据、面朝你的方向。

> 💡 如果复活位置被堵住了，仪式会自动取消并把玩偶**原地返还**给你——不会丢东西。

### 3. 创造模式提示

创造模式下玩偶不会被消耗——可以用来"复制"伙伴。但要注意，玩偶里保存的是**那只伙伴当时的全部数据**，不是一只新角色。

## ⚔️ 三把讨伐棒

模组为乌萨奇、小八、吉伊各做了一把专属武器，外观还原原作，自带强力附魔：

| 武器名称           | 基础属性 | 自带附魔      |
| :----------------- | :------- | :------------ |
| **乌萨奇的讨伐棒** | 铁剑属性 | 🔥 火焰附加 I |
| **小八的讨伐棒**   | 石剑属性 | 💨 击退 I     |
| **吉伊的讨伐棒**   | 石剑属性 | 💨 击退 I     |

讨伐棒同时被识别为"剑类"，可以作为剑士职业的触发武器——把它塞到伙伴主手里，它就既能用本人的专属武器，又能自动当剑士。
